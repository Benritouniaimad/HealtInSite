🎯 PROCHAINES ÉTAPES (DANS L'ORDRE)

1️⃣  LIRE LE QUICKSTART
   📖 Ouvre QUICKSTART.md
   ⏱️  Temps : 2 minutes

2️⃣  INSTALLER LE PROJET
   Windows : .\setup.bat
   Linux/Mac : bash setup.sh
   ⏱️  Temps : 3 minutes

3️⃣  ENTRAÎNER LE MODÈLE
   cd backend
   python -m backend.app.train_model
   ⏱️  Temps : 1 minute

4️⃣  LANCER L'API
   Terminal 1 :
   cd backend
   uvicorn backend.app.main:app --reload
   ⏱️  Temps : 10 secondes

5️⃣  LANCER LE FRONTEND
   Terminal 2 :
   cd frontend
   npm run dev
   ⏱️  Temps : 10 secondes

6️⃣  TESTER L'APPLICATION
   🌐 Ouvre http://localhost:3000
   ✅ Fais une prédiction
   ✅ Explore les données
   ⏱️  Temps : 5 minutes

7️⃣  PRÉPARER LA PRÉSENTATION
   📖 Lis PRESENTATION.md
   🎤 Prépare ta démo
   ⏱️  Temps : 30 minutes
